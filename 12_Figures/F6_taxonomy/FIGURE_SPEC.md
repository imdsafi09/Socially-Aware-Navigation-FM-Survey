# F6 Figure Specification: Multi-Axis Taxonomy (conceptual)

**Scientific question:** which independent dimensions describe a foundation-model social-navigation system, and what categories does each contain?
- **Type:** conceptual framework figure.
- **Source:** FINAL_SURVEY_TAXONOMY.md.
- **RQ:** RQ3, RQ4 (definitions); frames RQ1, RQ6.

## Layout: five parallel columns, not a pipeline
Left → right: **A Social representation | B FM role | D Navigation interface | C Social capability | E Evidence profile**.
- **Ordering rationale:** the columns follow the reading order "what is encoded → what the FM does → how it acts → what it targets → how it is shown". The figure states explicitly: *axes are independent; papers are multi-label on A, B, C and D; no column is derived from another*.
- **Connectors:** thin grey **dotted** lines between the columns, labelled "a paper is coded on every axis". Do **not** draw arrows; arrows would suggest causality.
- **Column content:**
  - **A:** 7 chips (A0–A6) with one-line definitions.
  - **B:** 5 chips (R1–R5).
  - **D:** 9 chips (D0–D8) in a grid with **no ordering cues** (no gradient, no staircase), titled "categorical; not a maturity ranking". Chips are grouped visually by consumer: *none* (D0), *classical planner* (D1–D4), *learned policy* (D5, D6), *training pipeline* (D7), *people* (D8).
  - **C:** a small tree of 5 families → 15 leaves.
  - **E:** six independent toggles EV1–EV6, with value sets listed under each.
- **Counts:** each chip carries a small direct-paper count (non-exclusive), e.g. "D3 · 11". A footnote states the counts are non-exclusive and come from QUANTITATIVE_FINDINGS QF06–QF19.
- **Cross-cutting ring:** a dashed rounded rectangle surrounding all columns, labelled "Cross-cutting attributes (not taxonomy classes)": temporal coupling · memory · continual adaptation · explanation output · FM-independent safety guard · uncertainty · hallucination mitigation · privacy · inference location.
- **Worked example strip (bottom):** one paper traced across the axes, shown as small highlighted chips. Example: G2-Nav → A1 A2 A3 A5 · R1 R2 · D3 · SAF1/SAF2 · EV1 + EV3 systematic + EV4 unscripted.

## Caption concept
"A five-axis taxonomy of foundation-model social navigation. Representation (A), FM role (B), navigation interface (D), targeted capability (C) and evidence profile (E) are coded independently for each paper. Interface classes are categorical, not a maturity order. Cross-cutting attributes (outer ring) describe architecture and reliability properties and are kept separate from the method taxonomy. Counts refer to the 41 direct papers (non-exclusive)."

## Do-not rules
- No arrows between axes.
- No size or colour gradient on D.
- Legacy F/I/E/C codes must not appear.
